# כתוב 1.3.0 — גרסת ניסיון חינמית למחשב

מתקין עברי ל־Windows 10/11 x64 (Intel/AMD), ללא צורך ב־Python מותקן או בהרשאות מנהל. יצירת כתוביות ועיבוד הסרטון מתבצעים במחשב, ללא סימן מים וללא תשלום.

**זו גרסת ניסיון ללא חתימה דיגיטלית.** שם הקובץ כולל `UNSIGNED`. Windows עשוי להציג ״מפרסם לא ידוע״ או אזהרת SmartScreen. SHA-256 בודק את התאמת הקובץ שירד לתוצר שפורסם; הוא אינו מאמת זהות מפרסם.

## הורדה והתקנה

1. הורידו את `Katuv-1.3.0-Windows-UNSIGNED.exe` ואת קובץ ה־`.exe.sha256` המצורף.
2. בתיקיית ההורדות הריצו `Get-FileHash -LiteralPath '.\Katuv-1.3.0-Windows-UNSIGNED.exe' -Algorithm SHA256` ב־PowerShell והשוו לקובץ החותמת. 64 התווים צריכים להתאים, ללא תלות בגודל האותיות.
3. אחרי אימות המקור והחותמת, הפעילו את המתקין. אם מופיעה אזהרת SmartScreen, אפשר לבחור ״מידע נוסף״ ואז ״הפעל בכל זאת״, אם Windows מציע זאת. אין צורך לכבות הגנות Windows.
4. פתחו **כתוב** ובחרו **הכנת המחשב** להורדת מודלים. נדרשים אינטרנט ולפחות 10 GB פנויים להתקנה, ומקום נוסף למודלים ולסרטונים. לאחר ההכנה אפשר לעבוד ללא אינטרנט עם הרכיבים שהורדו.

## מה נכלל

- אשף התקנה עברי, קיצורי דרך והסרה דרך Windows.
- התקנה חוזרת ושדרוג בסביבה חדשה, עם בדיקת תקינות ושימור הגרסה הקודמת.
- חסימת שדרוג והסרה בזמן עיבוד; פרויקטים ומטמונים נשמרים בהסרה.
- טיפול בפרויקטים פגומים, העלאות שנכשלו, פורט תפוס ותקלות הורדה.
- בחירה מתמשכת ומפורשת במודלים האופציונליים.

ה־EXE נבנה מ־checkout נקי ועבר בדיקות קוד, ביקורת חבילה ובדיקת התקנה, התקנה חוזרת, הפעלה והסרה ב־Windows של GitHub Actions. **בדיקות קבלה בחשבון רגיל ב־Windows 10/11 במחשב נוסף והאזנה אנושית לדיבור ולשירה עדיין נדרשות לפני גרסה יציבה.** תזמון אוטומטי הוא אומדן ודורש בדיקה בעורך.
